# Discover Georgia (საქართველო)

A beautiful, responsive website about Georgia featuring information about the country's culture, landscapes, resorts, cuisine, and traditions. The website is built with React, TypeScript, and modern web technologies.

## Features

- **Responsive Design**: Fully responsive design that works on mobile, tablet, and desktop
- **Bilingual Support**: Content in both English and Russian with language switching
- **Georgian Elements**: Authentic Georgian language elements throughout the site
- **Interactive Map**: Map of Georgia showing major cities and landmarks
- **Georgian Alphabet**: Display of the unique Georgian alphabet
- **Weather Widget**: Current weather conditions in major Georgian cities
- **Photo Gallery**: Beautiful images of Georgia's landscapes and culture
- **Georgian Language Lessons**: Information about learning the Georgian language

## Technology Stack

- React
- TypeScript
- TailwindCSS
- Shadcn/UI Components
- Leaflet Maps
- Weather API Integration

## Pages

- **Home**: Overview of Georgia with hero image and sections previews
- **About**: Detailed information about Georgia's history and geography
- **Gallery**: Photo gallery with images from Georgia
- **Resorts**: Information about popular tourist destinations in Georgia
- **Cuisine**: Details about Georgian food and wine
- **Traditions**: Cultural traditions and customs of Georgia
- **Language Lessons**: Information about learning Georgian

## Getting Started

1. Clone the repository
2. Install dependencies with `npm install`
3. Start the development server with `npm run dev`
4. Open [http://localhost:5000](http://localhost:5000) in your browser

## Environment Variables

The project uses these environment variables:
- `VITE_WEATHER_API_KEY`: API key for weather data
- `UNSPLASH_ACCESS_KEY`: For fetching images (optional)
